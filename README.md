Sistema de Gestión para Peluquería

Alumnos: Matias Rivera
                  Sanchez Alvaro

Sistema integral desarrollado para la gestión de turnos en peluquería, compuesto por una plataforma web administrativa y una aplicación móvil para clientes.
web-barberia`: Código fuente de la interfaz administrativa.
app-cliente`: Código fuente de la aplicación móvil (React Native/Expo,JavaScript y TypeScript.).

Instrucciones 

1. Visualización del Código
Todo el código fuente se encuentra disponible en este repositorio para su revisión.

2. Aplicación Móvil (APK)
La aplicación fue compilada utilizando EAS Build.
Descargar APK aquí  https://drive.google.com/file/d/1A6IOwuuTAtsgo2fD3ynsJWuQFyfnPg5w/view?usp=sharing
Para instalar en Android, asegúrese de habilitar la instalación desde "Fuentes desconocidas" en los ajustes de seguridad de su dispositivo.

Requisitos previos para visualizar en pc
1.	Node.js: Descargar e instalar desde nodejs.org.
2.	Git: Instalado en el sistema.
Cómo ejecutar el proyecto 
1.	Clonar el repositorio: Abrir la terminal y escribir: git clone [https://github.com/matiasriveraXD/Proyecto-Barberia.git](https://github.com/matiasriveraXD/Proyecto-Barberia.git)
2.	Ejecutar la Web:
o	cd Proyecto-Barberia/web-barberia

Video de la app final: https://drive.google.com/file/d/1XUWv3DEe4L8TmqffkgpyrGitOgPoakAr/view?usp=sharing 
o	npm install
o	npm start (Esto abrirá la web en el navegador).
4.	Ejecutar la App (Modo desarrollo):
o	cd ../app-cliente
o	npm install
o	npx expo start (Se generará un código QR que se puede escanear con la app Expo Go en cualquier celular).
